Entrar no painel

Cole abaixo a chave de acesso (token do GitHub) que foi criada para você. Sem ela não é possível alterar o site.

Como criar a chave de acesso (só na primeira vez)
  1. Entre no GitHub com a conta dona do site e abra Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Clique em Generate new token. Dê um nome (ex.: "Painel Maison").
  3. Em Repository access escolha Only select repositories e marque só o repositório graci.
  4. Em Permissions → Repository permissions, deixe Contents como Read and write.
  5. Escolha a validade, gere o token e copie (ele só aparece uma vez). Cole aqui em cima.

A chave fica só no seu navegador e é enviada apenas ao GitHub para salvar os textos.
